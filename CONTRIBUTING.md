# Contributing to CELL

CELL is at the concept and specification stage. Contributions that clarify the model are especially welcome.

## Before implementing a feature
1. Open an issue describing the problem and intended behavior.
2. Explain whether the proposal reflects the original vision or is a new implementation choice.
3. Discuss compatibility, security, migration, memory, and evolution implications where relevant.
4. Prefer small, testable proposals.

## Development expectations
- Include tests for behavior changes.
- Document breaking changes.
- Avoid presenting conceptual syntax as implemented syntax.
- Do not execute migrated code outside a sandbox or trust a peer merely because it is discoverable.

## Pull requests
Keep changes focused and explain how they advance a roadmap milestone.
