# CELL Glossary

- **Cell / CELL Function:** an autonomous logical unit combining code with associated state and adaptation components.
- **Code:** the executable body or portable intermediate representation.
- **DNA:** structured metadata describing a cell's structure, parameters, allowed transformations, constraints, and lineage.
- **Memory:** state or experience retained by a cell under an explicit policy.
- **NeuralCore:** a lightweight neural component associated with a cell.
- **Evolution:** the controlled creation and evaluation of candidate cell variants.
- **Migration:** transfer of a cell and the state needed to resume it on another compatible node.
- **Peer:** a runtime node that can communicate directly with other participating nodes.
- **Checkpoint:** a portable snapshot sufficient to resume a supported cell at a defined point.
- **Fencing:** a mechanism that prevents a former owner from continuing to modify state after ownership has moved.
