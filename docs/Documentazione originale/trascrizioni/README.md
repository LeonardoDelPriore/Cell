# Trascrizioni originali

Ogni file di questa cartella è la trascrizione di una fotografia in `docs/Documentazione originale/`. In cima a ogni file c’è la foto. Il testo segue quello che si legge: non corregge l’ortografia, non completa le frasi tagliate e segna con parentesi quadre le parole non stabili.

Le fotografie restano la fonte. Queste trascrizioni sono una lettura diplomatica del 14 novembre 2026, da affiancare agli appunti nuovi e non da sostituire alle carte.

Le 49 foto sono state scattate il 13 ottobre 2026. L’ordine qui sotto è l’ordine di lettura, non l’ordine di scatto.
